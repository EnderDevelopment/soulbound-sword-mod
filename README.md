# Soulbound Sword Mod

Unbreakable diamond sword with killstreak mechanics for Fabric 1.21.4

## Features

- Unbreakable diamond sword that persists on death
- Killstreak mechanics for increased damage with consecutive kills

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.15.7 or later
- Fabric API

## Installation

1. Download the mod JAR file from the [releases page](https://github.com/yourusername/soulboundswordmod/releases).
2. Place the JAR file in your `mods` folder.
3. Launch Minecraft with Fabric.

## Usage

- Craft the Soulbound Sword using a diamond sword and a soulbound enchantment (if applicable).
- The sword will persist on death and cannot be repaired or enchanted.
- Gain killstreaks to increase damage with consecutive kills.
